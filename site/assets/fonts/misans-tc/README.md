# MiSansTC

MiSans 的繁中版。取自 npm 包 `misans@5.0.0`（dsrkafuu/misans）里的 `lib/TC`，只留了 Regular 和 Semibold 两个字重（同官网用的那两个）。
每个字重按字符范围切成小块，浏览器只下载页面上用到的那几块。

繁中页面以它为主、简中版 MiSans 补字；其他页面反过来，用它补简中版没有的字（见 style.css 的 --font-sans）。

字体版权归小米，按《MiSans 字体知识产权许可协议》使用：
https://hyperos.mi.com/font-download/MiSans%E5%AD%97%E4%BD%93%E7%9F%A5%E8%AF%86%E4%BA%A7%E6%9D%83%E8%AE%B8%E5%8F%AF%E5%8D%8F%E8%AE%AE.pdf

协议要求：在作品中注明使用了 MiSans；不得改编字体；不得单独分发或售卖字体文件。
